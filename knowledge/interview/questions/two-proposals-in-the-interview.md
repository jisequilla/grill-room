# Two proposals in the Interview

Inside Interview, a [Proposal](/interview/language/proposal.md) is a pending suggestion about a decision's own answer, and a [round proposal](/interview/language/round-proposal.md) is what an interviewer turn returns for a round. One word with two meanings in one context breaks the rule of its language. Both are recorded as they stand: the code and `GLOSSARY.md` already use these names.[^contexts]

It was deferred because renaming a code-facing word is a code change, to be debated before it is made. It closes with a decision that keeps both, or names one of them anew, with the old name added to the Term's words to avoid and a ticket for the code.[^contexts]
