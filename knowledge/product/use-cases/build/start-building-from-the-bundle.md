# Start building from the bundle

Pipe wants a Start Building Session action that opens a Claude session loaded with the handoff, so the agent starts reading and building at once.[^meeting]

**Technical level.** Knowing how to start an agent session on a handoff by hand is another step a non-technical owner may not have.

**Missing.** The handoff is a document the owner or their agent follows; nothing in the app opens a session.
